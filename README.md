# زوم همراه - Android starter

این نسخه اولیه یک پوسته اندرویدی Flutter است که فروشگاه https://zoomhamrah.ir را داخل اپ باز می‌کند.

## ساخت APK بدون کامپیوتر
1. فایل‌های این بسته را در ریشه مخزن GitHub با نام `tobolo/zoomhamrah-app` بارگذاری کنید.
2. در GitHub وارد زبانه **Actions** شوید.
3. گردش‌کار **Build Android APK** را انتخاب و روی **Run workflow** بزنید.
4. پس از پایان موفق، از بخش Artifacts فایل `zoomhamrah-android-apk` را دریافت کنید.
5. فایل APK داخل ZIP خروجی قرار دارد.

## نکات مهم
- این نسخه اولیه برای آزمایش است و هنوز اعلان پوش Firebase، امضای اختصاصی انتشار و آزمون درگاه‌های بانکی در آن پیکربندی نشده‌اند.
- صفحات فروشگاه و فرایندهای ورود/سبد/پرداخت در WebView و بر پایه سایت فعلی اجرا می‌شوند.
- پیش از انتشار عمومی باید روی گوشی‌های مختلف، ورود، سبد خرید، درگاه پرداخت، بازگشت از درگاه و دانلودها آزمایش شوند.
- برای اعلان‌های واقعی باید Firebase project و فایل پیکربندی Android اضافه شود.
